# BemVindo
Este é meu primeiro projeto para a disciplina de mentoria de carreira

O código que está no arquivo arcano.c calcula seu arcano pessoal no tarot

Copie o código e execute-o em seu compilador favorito

A cada entrada o código pede que seja digitado primeiro o seu dia de nascimento, depois o mês e depois o ano

O resultado é algo entre 3 e 24

Código feito inteiramente em linguagem C
